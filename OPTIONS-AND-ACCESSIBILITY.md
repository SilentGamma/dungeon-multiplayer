# Options, audio and accessibility

Options is available on every non-playing screen through the fixed Options control or O. During dungeon play, Pause (Escape or O) shows the options directly under Resume; there is no extra Options button inside the pause menu. End-of-run screens expose the standalone Options control again. Pausing only stops the local player; the dungeon continues running. Returning from pause restores focus to the dungeon so Space remains an action shortcut.

The three sliders are independent and saved in the current browser profile. Music defaults to 50% on the slider: each active track targets 0.32 × 0.50 = 0.16 HTML audio volume. The previous untouched 25% default migrates to 50%; saved custom levels are retained. Menu, exploration and combat themes all use this channel. Setting Music to zero stops it immediately; ordinary changes fade smoothly. Effects defaults to 70% and controls attacks, enemies, impacts, pots, pickups, healing and revives. Music controls all long themes and musical event tracks, including the castle entry, dungeon drums and clear/goal fanfares. Menu sounds defaults to 50% and controls navigation cues only. Tracks fade out and reset during page/floor transitions; dungeon entrance drums start after the reveal. Live gain buses update playing effects as well as future sounds. Mute all sounds retains the existing mute preference and does not discard the slider levels.

High contrast uses bright text, solid dark panels, stronger control/focus outlines, clearer meters, increased dungeon contrast/brightness and outlined canvas labels. Dyslexia-friendly text uses locally bundled OpenDyslexic regular and bold on UI text, headings, controls and all canvas labels. Turning these off restores the original style. Preferences persist across reloads, navigation and new runs.

Solo S rank now requires a true one-player run to finish deathless within a provisional 10:00 full-game limit. Solo A covers slower completions through 12:00; later successful finishes get B. Failure remains F. The 10-minute target is 16.7% tighter than the prior 12-minute A baseline. It is a starting design value, not a measured completion percentile; successful timed runs across roles should guide tuning. Multiplayer keeps its deathless S rule and existing A pace adjustment. Initial party size fixes solo classification, so disconnects cannot impose a solo challenge mid-run. Pauses and floor transitions remain part of elapsed run time. Existing GOLD unlocks are retained; future solo GOLD awards require the new S condition.

Validation: npm test, independent mixer and persistence tests, font bytes/MIME/license delivery, canvas font/contrast rendering, solo threshold boundaries and GOLD award integration, and browser checks of standalone and inline pause controls.
